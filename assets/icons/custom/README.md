# Custom answer pictograms

Original geometric SVGs for the sorter, covered by the project GPL-3.0 license.
All use solid white shapes on a transparent square canvas.

- `noncooperation.svg`: open palm for nonviolent refusal.
- `legal-decision.svg`: gavel for deciding legal exceptions.
- `crown-and-church.svg`: crown and cross for religious monarchy.
- `religious-guild.svg`: wrench and cross for religious occupational bodies.
