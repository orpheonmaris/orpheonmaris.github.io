# Editorial banner artwork

Hand-drawn SVG banners made for the site in review rounds, with no generated artwork.

- `schmittianism.svg` (R63): a field divided light and dark for the friend–enemy distinction, with a crowned sword on the dividing line for the sovereign decision that draws it. The sword is counterchanged, belonging to neither side. Replaces an imported banner that used a swastika.
- `integralism.svg` (R63): the crossed keys of the Church above a crown, for the temporal power subordinated to the spiritual power. Replaces the sigma of Brazilian Integralism.

Thumbnails (360×240) and display images (960×640) are rendered from these files.
