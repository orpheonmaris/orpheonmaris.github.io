# Editorial banner artwork

Hand-drawn SVG banners made for the site in review rounds, with no generated artwork.

- `schmittianism.svg` (R63): a sword through a broken bar, for the decision that suspends the norm. Replaces an imported banner that used a swastika.
- `integralism.svg` (R63): a cross above a crown, for the temporal power subordinated to the spiritual power. Replaces the sigma of Brazilian Integralism.

Thumbnails (360×240) and display images (960×640) are rendered from these files.
